# AI Tutor – Learn Anything Simply

AI Tutor is a responsive educational website concept that helps students explore academic topics through simple explanations, examples, key-point summaries and quick quizzes.

## Features

- Search for topics in the sample lesson library.
- Filter lessons by Science, Mathematics, Computer Science, Business and Humanities.
- Read a student-friendly explanation and a practical example.
- Review key points for each lesson.
- Attempt a multiple-choice knowledge-check question.
- Print a selected study guide.
- Responsive layout for desktop, tablet and mobile screens.

## Technologies Used

- **HTML5** – page structure
- **CSS3** – styling and responsive layout
- **JavaScript** – topic search, subject filters, lesson display and quiz interaction

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or open it with a browser.
4. Search for a topic or select a subject category.

No installation or build step is required.

## Important Project Note

This version uses a **built-in sample lesson library** in `script.js`. It demonstrates the front-end experience, but it does **not** connect to a live AI model, external AI API, database or backend server. Topics that are not in the sample library will not receive a newly generated AI explanation.

A future version could add a secure backend and an approved AI API to generate explanations for a wider range of topics. API keys should never be placed directly in front-end JavaScript or committed to a public GitHub repository.
